1. Общие положения

Настоящая Политика обработки персональных данных (далее — «Политика») определяет порядок сбора, хранения и защиты информации, предоставляемой пользователями сайта стоматологической клиники «Оникс Dent» (First Dental Group), юридическое наименование: [ЗАПОЛНИТЬ: ООО «...»], ОГРН [ЗАПОЛНИТЬ: ОГРН], ИНН [ЗАПОЛНИТЬ: ИНН] (далее — «Оператор»).

2. Состав собираемых персональных данных

Оператор обрабатывает только те персональные данные, которые пользователь осознанно передает при заполнении форм записи на консультацию на сайте:

  • Имя пользователя;
  • Контактный номер телефона;
  • Выбранное направление лечения и текстовые комментарии / пожелания по времени приёма.

3. Цели обработки данных

Персональные данные собираются исключительно для:

  • Связи администратора клиники с пользователем для подтверждения даты и времени консультации;
  • Предоставления первичной информации об услугах клиники;
  • Улучшения качества обслуживания пациентов.

4. Защита и нераспространение данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа. Персональные данные никогда и ни при каких обстоятельствах не передаются третьим лицам, за исключением случаев, прямо предусмотренных действующим законодательством.

5. Контакты для отзыва согласия

Пользователь может в любой момент отозвать свое согласие на обработку персональных данных, направив соответствующее заявление на электронную почту: [ЗАПОЛНИТЬ: Email клиники] или по телефону: [ЗАПОЛНИТЬ: Телефон клиники].
